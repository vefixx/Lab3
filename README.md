## Задача 1.2

### Текст задачи
```
Составить программу, которая в списке L заменяет первое вхождение списка L1 (если такое есть) на список L2.
```


### Алгоритм решения

1. В классе `Solutions` создать статический метод `TryReplaceFirstEntry<T>(List<T> l1, List<T> l2, List<T> l3)`, который возвращает `bool`.
2. В начале метода проверить: если `l2.Count == 0` (пустой подсписок) или `l2.Count > l1.Count` (подсписок длиннее основного), вернуть `false`, список `l1` не менять.
3. Вызвать приватный метод `FindFirstEntry(l1, l2)`, он возвращает индекс первого вхождения `l2` в `l1` или `-1`, если вхождения нет.
4. В методе `FindFirstEntry<T>`:
    - найти последний возможный индекс начала: `lastStart = l1.Count - l2.Count`;
    - во внешнем цикле перебрать индексы `i` от `0` до `lastStart`;
    - для каждого `i` установить флаг `matches = true` и во внутреннем цикле по `j` от `0` до `l2.Count - 1` сравнить `l1[i + j]` и `l2[j]` через `Equals`;
    - при несовпадении снять флаг `matches` и выйти из внутреннего цикла через `break`;
    - если флаг остался `true`, вернуть `i`;
    - если ничего не нашли, вернуть `-1`.
5. Если `FindFirstEntry` вернул `-1`, метод `TryReplaceFirstEntry` возвращает `false`, список не изменен.
6. Иначе удалить найденный фрагмент: `l1.RemoveRange(startIndex, l2.Count)`.
7. Вставить элементы замены на то же место: `l1.InsertRange(startIndex, l3)`. Если `l3` пустой, вставка ничего не добавит, произойдет просто удаление `l2`.
8. Вернуть `true`.
9. В `Program.cs` в методе `Task1()` запросить у пользователя элементы трех списков (`l1`, `l2`, `l3`) одной строкой через пробел, разбить строку методом `Split` с флагом `StringSplitOptions.RemoveEmptyEntries`, преобразовать каждый элемент в `int` и добавить в `List<int>`.
10. Вызвать `Solutions.TryReplaceFirstEntry`, вывести возвращенное значение, а при успехе еще и измененный список `l1` через `string.Join(", ", l1)`.

## Задача 2.2

### Текст задачи
```
Сортировать элементов списка по возрастанию
```



### Алгоритм решения

1. В классе `Solutions` создать статический метод `SortAsc<T>(LinkedList<T> list)`, сортирующий связный список по возрастанию.
2. Если `list.Count < 2`, сразу выйти из метода: список из нуля или одного элемента уже отсортирован.
3. Получить компаратор `Comparer<T> comparer = Comparer<T>.Default`, он использует `IComparable<T>` для типа `T`.
4. Реализовать сортировку пузырьком по узлам списка:
    - внешний цикл по `i` от `0` до `list.Count - 2`;
    - на каждом проходе установить флаг `swapped = false` и указатель `curr = list.First`;
    - внутренний цикл по `j` от `0` до `list.Count - i - 2`;
    - сравнить значения соседних узлов: `comparer.Compare(curr.Value, curr.Next.Value) > 0`;
    - если левое больше правого, обменять значения узлов через временную переменную `temp` и установить `swapped = true`;
    - сдвинуть указатель `curr = curr.Next`.
5. После каждого прохода, если `swapped == false`, прервать внешний цикл через `break`: обменов не было, список уже отсортирован.
6. Так как на каждом проходе наибольший элемент всплывает в конец, длина внутренней части уменьшается на `i`.
7. В `Program.cs` в методе `Task2()` считать строку чисел через пробел, сформировать `List<int>`, передать его в конструктор `LinkedList<int>`, вызвать `Solutions.SortAsc` и вывести отсортированный список через `string.Join(", ", list)`.

# Задание 3

## Задача 3.2

### Текст задачи
```
Есть перечень компьютерных игр. Студенты группы играют в какие-либо из этих игр. Известно
для каждого студента, в какие игры он играет. Определить:
• в какие игры из перечня играют все студенты группы;
• в какие игры из перечня играют некоторые студенты группы;
• в какие игры из перечня не играет ни один из студентов группы?
```



### Алгоритм решения

1. В классе `Solutions` создать статический метод `AnalyzeGameSets(HashSet<string> allGames, List<HashSet<string>> studentGames, out HashSet<string> allPlay, out HashSet<string> somePlay, out HashSet<string> nonePlay)`.
2. Инициализировать результирующие множества:
    - `allPlay = new HashSet<string>(allGames)`, копия всех игр, в ней останутся только игры, в которые играют все студенты;
    - `somePlay = new HashSet<string>()`, пустое множество, в него попадут игры, в которые играет хотя бы один студент;
    - `nonePlay = new HashSet<string>(allGames)`, копия всех игр, из нее будут удалены игры, в которые играет кто-либо.
3. В цикле `foreach` перебрать множества игр каждого студента из списка `studentGames`:
    - `allPlay.IntersectWith(student)`: игра остается, только если она есть у каждого студента;
    - `somePlay.UnionWith(student)`: накапливаются все встреченные игры.
4. После цикла выполнить `somePlay.IntersectWith(allGames)`, чтобы отбросить игры, которых нет в общем списке.
5. Вычислить `nonePlay.ExceptWith(somePlay)`: из общего списка удаляются все игры, в которые играет хотя бы один студент, остаются игры, в которые не играет никто.
6. Вернуть результаты через `out`-параметры.
7. В `Program.cs` в методе `Task3()` считать общий список игр (строка через пробел, преобразовать в `HashSet<string>`), затем количество студентов `n`, и в цикле `for` от `0` до `n - 1` считать множество игр каждого студента, добавляя его в `List<HashSet<string>>`.
8. Вызвать `Solutions.AnalyzeGameSets` и вывести три полученных множества через `string.Join(", ", ...)`.

```

### Алгоритм решения

1. В классе `Solutions` создать статический метод `FindMissingDeafChars(string filePath)`, возвращающий `char[]`.
2. Создать множество глухих согласных: `HashSet<char> deaf = { 'п', 'ф', 'к', 'т', 'ш', 'с', 'х', 'ц', 'ч', 'щ' }`.
3. Создать пустое множество `HashSet<char> textLetters` для букв, встретившихся в тексте.
4. Открыть файл через `StreamReader(filePath, System.Text.Encoding.UTF8)` и поместить чтение в блок `try`, а закрытие потока в блок `finally` (`reader.Close()`), чтобы файл закрывался даже при исключении.

6. Для каждого символа строки:
    - привести его к нижнему регистру: `char lower = char.ToLower(c)`;
    - проверить, что это буква: `char.IsLetter(lower)` (цифры, пробелы и знаки препинания игнорируются);
    - добавить букву в `textLetters`; дубликаты множество отбрасывает само.
7. После чтения всего файла выполнить `deaf.ExceptWith(textLetters)`: в множестве останутся только те глухие согласные, которых нет в тексте.
8. Скопировать результат в массив: создать `char[] result = new char[deaf.Count]` и вызвать `deaf.CopyTo(result)`.
9. Отсортировать массив `Array.Sort(result)` для алфавитного порядка вывода, так как `HashSet` не гарантирует порядок элементов.
10. Вернуть массив `result`.
11. В `Program.cs` в методе `Task4()` запросить у пользователя только имя (путь) файла, вызвать `Solutions.FindMissingDeafChars` и вывести результат, преобразовав массив в строку конструктором `new string(res)`.

```
На городской олимпиаде по информатике участникам было предложено выполнить 3 задания,
каждое из которых оценивалось по 25-балльной шкале. Известно, что общее количество
участников первого тура олимпиады не превосходит 250 человек. На вход программы подаются

При этом <Фамилия> и <Имя>, <Имя> и <Баллы> разделены одним пробелом. Примеры входных строк:

Калиниченко Иван 14 19 15
Напишите программу, которая будет выводить на экран фамилию и имя участника, набравшего

    - вернуть найденный максимум.
7. В `PrintWinners` в цикле `foreach` вывести все имена из `scoreToNames[maxScore]`, то есть всех победителей, а не только первого.

# Задание 6.2 и 7.2

### Текст задачи
| Название класса | Поля | Методы |
|-----------------|------|--------|
|Money|uint rubles, byte kopeks|Добавление произвольного количества копеек (uint) к объекту типа Money. Результат должен быть типа Money.|

Перегрузка операторов:
```
Унарные операции:
-- вычитание копейки из объекта типа Money
++ добавление копейки к объекту типа Money
Операции приведения типа:
uint (неявная) результатом является количество рублей (копейки
отбрасываются);
double (явная) результатом является копейки, переведенные в рубли,
целые рубли отбрасываются, результат <1.
Бинарные операции:
- Money m, целое число (лево- и правосторонние операции) вычитание
копеек из денежной суммы
```

### Алгоритм решения

1. Создать класс `Money` с приватными полями `private uint _rubles` и `private byte _kopeks`. Тип `uint` исключает отрицательные суммы, тип `byte` ограничивает копейки сверху значением 255.
2. Реализовать конструктор `Money(uint rubles, byte kopeks)`, присваивающий значения через свойства, чтобы срабатывала валидация.
3. Реализовать свойство `Rubles` с открытым `get` и `private set`: извне сумма изменяться не может.
4. Реализовать свойство `Kopeks` с `private set`, в котором проверить условие `value > 99` и при его выполнении выбросить `ArgumentException("Копейки должны быть в диапазоне 0-99")`.
5. Реализовать метод `AddKopeks(uint kopeksToAdd)`:
    - перевести всю сумму в копейки и прибавить добавляемое значение: `totalKopeks = Rubles * 100 + Kopeks + kopeksToAdd`;
    - вычислить новые рубли как `totalKopeks / 100` и новые копейки как `(byte)(totalKopeks % 100)`;
    - вернуть новый объект `Money`, не изменяя исходный.
6. Реализовать перегрузку унарного оператора `--`:
    - перевести сумму в копейки;
    - если она равна нулю, выбросить `InvalidOperationException("Нельзя вычесть копейку из нулевой суммы")`;
    - уменьшить количество копеек на 1, пересчитать рубли и копейки, записать их в поля объекта и вернуть его.
7. Реализовать перегрузки бинарного оператора `+`: `operator +(Money m, uint kopeks)` и `operator +(uint kopeks, Money m)`. Обе вызывают метод `AddKopeks`, что обеспечивает коммутативность и отсутствие дублирования логики.
8. Реализовать `operator -(Money m, uint kopeks)`:
    - перевести сумму в копейки;
    - если вычитаемое больше имеющейся суммы, выбросить `InvalidOperationException("Результат не может быть отрицательным")`;
    - иначе выполнить вычитание и вернуть новый объект `Money(total / 100, (byte)(total % 100))`.
9. Реализовать `operator -(uint kopeks, Money m)` симметрично: если сумма объекта больше уменьшаемого числа копеек, выбросить `InvalidOperationException`, иначе вернуть новый объект с разностью.
10. Реализовать явное приведение `explicit operator uint(Money m)`, возвращает `m.Rubles`, то есть целое число рублей.
11. Реализовать неявное приведение `implicit operator double(Money m)`, возвращает дробное представление суммы (`Rubles + Kopeks / 100.0`); деление на `100.0` выполняется в вещественном типе.
12. Переопределить метод `ToString()`, возвращающий строку вида `$"{_rubles} руб. {_kopeks} коп."`.
13. В `Program.cs` в методе `Task1()` протестировать все перегрузки и члены класса: конструктор и `ToString`, `AddKopeks`, `+` в обоих порядках операндов, `-` в обоих порядках операндов, `--`, явное приведение к `uint`, неявное приведение к `double`.
14. Негативные проверки (копейки больше 99, вычитание из меньшей суммы, декремент нулевой суммы) выполнять в блоках `try/catch`, выводя тип возникшего исключения, чтобы программа продолжала работать.
